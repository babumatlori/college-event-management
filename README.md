# College Event Management System
Full-stack web application for managing college events.
This is web application, were user can login has per his role admin, student, organizer and process his role.
Jwt is used for role based authentications.

## Tech stack
-Frontend: React
-Backend: Spring Boot
-Database: MySQL
-Authentication: JWT

## Project Structure
-college-event - React frontend
-college-event-backend - Spring Boot backend

## How to Run
### Frontend
cd college-event
npm install
npm run dev

### Backend
Open in Eclipse
Run SpringBootApplication
